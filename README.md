# JSON 格式化工作台

一个纯前端的 JSON 格式化工具，零依赖、零后端，打开即用。

## 功能

- **格式化 / 压缩 / 验证**：报错带行列号定位（第 X 行，第 Y 列）
- **可拖动分隔条**：左右两栏宽度自由调整，比例自动记住
- **树形视图**：可折叠的节点树，点击叶子值可复制
- **修复 JSON**：自动修掉尾随逗号、单引号、未加引号的键、注释
- **JSONPath 查询**：支持 `$.a.b[0]`、`$..key`、`$.*`、`[*]`，点结果可复制
- **生成 TS 类型**：根据 JSON 推断 TypeScript 接口，可复制或下载 `types.ts`
- **转义 / 去转义**：JSON 字符串与原文互转
- **分享链接**：把当前数据编进 URL，打开链接即是这份数据
- **历史记录**：最近 5 次输入，下拉可恢复
- **多主题**：深色、浅色、复古、Oracle、DataGrip 五种主题，右上角切换，自动记住
- **按键名排序**：递归排序所有对象键
- **粘贴后自动格式化**：可开关
- **文件支持**：打开 `.json` 文件、拖放文件、下载结果

## 本地运行

直接用浏览器打开 `index.html` 即可，或起一个静态服务器：

```bash
npx serve .
# 或
python3 -m http.server 8000
```

## 部署

纯静态站，可直接部署到 Vercel / GitHub Pages / 任意静态托管。
