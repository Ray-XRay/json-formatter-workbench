# JSON 格式化工作台

一个纯前端的 JSON 格式化工具，零依赖、零后端，打开即用。

## 功能

- **格式化 / 压缩 / 验证**：报错带行列号定位（第 X 行，第 Y 列）
- **界面**：一行工具栏 +「更多工具」下拉菜单，JSONPath 栏按需展开，输入区自带示例/打开文件/粘贴/清空
- **树形视图**：可折叠的节点树，点击叶子值可复制
- **修复 JSON**：自动修掉尾随逗号、单引号、未加引号的键、注释
- **JSONPath 查询**：支持 `$.a.b[0]`、`$..key`、`$.*`、`[*]`，点结果可复制
- **生成类型**：下拉选择 TypeScript / Go / Python，根据 JSON 推断类型定义，可复制或下载
- **转 YAML**：一键把 JSON 转成 YAML
- **JSON 对比**：粘贴第二份 JSON，逐行高亮新增 / 删除的差异
- **转义 / 去转义**：JSON 字符串与原文互转
- **分享链接**：把当前数据编进 URL，打开链接即是这份数据
- **历史记录**：最近 5 次输入，下拉可恢复
- **多主题**：深色、浅色、复古、Oracle、Oracle 白、DataGrip、JetBrains 七种主题，右上角切换，自动记住
- **按键名排序**：递归排序所有对象键
- **粘贴后自动格式化**：可开关
- **文件支持**：打开 `.json` 文件、拖放文件、下载结果
- **快捷键**：Ctrl+Enter 格式化，Ctrl+A 选中格式化结果，Ctrl+Alt+C 复制结果（带颜色），Ctrl+Alt+M 复制为 Markdown 代码块，树形视图中 Ctrl+L 展开 / 再按一次折叠全部节点；Ctrl+Alt+S 或「更多工具」→「快捷键设置」可查看和修改全部快捷键，改完自动保存
- **复制 Markdown 代码块**：纯文本是 ```json 围栏，粘到 Notion / Jira 是代码块；同时带一份带颜色的 HTML，粘到 Word / 邮件保留主题颜色
- **树形搜索**：切到树形视图，顶部搜索框按 key 或值过滤节点，命中节点的祖先保留显示，Esc 或 × 清除恢复
- **输入草稿自动保存**：输入框内容自动存到浏览器里，刷新或下次打开自动恢复；分享链接优先于草稿，点「清空」会把草稿一起清掉

## 本地运行

直接用浏览器打开 `index.html` 即可，或起一个静态服务器：

```bash
npx serve .
# 或
python3 -m http.server 8000
```

## 部署

纯静态站，可直接部署到 Vercel / GitHub Pages / 任意静态托管。
