# JSON 格式化工作台

一个纯前端的 JSON 格式化工具，零依赖、零后端，打开即用。

## 功能

- **格式化**：美化 JSON，缩进可选 2 空格 / 4 空格 / Tab
- **压缩**：一键压成单行
- **验证**：报错带行列号定位（第 X 行，第 Y 列）
- **树形视图**：可折叠的节点树，点击叶子值可复制
- **按键名排序**：递归排序所有对象键
- **粘贴后自动格式化**：可开关
- **文件支持**：打开 `.json` 文件、拖放文件、下载格式化结果
- **复制**：一键复制格式化结果

## 本地运行

直接用浏览器打开 `index.html` 即可，或起一个静态服务器：

```bash
npx serve .
# 或
python3 -m http.server 8000
```

## 部署

纯静态站，可直接部署到 Vercel / GitHub Pages / 任意静态托管。
