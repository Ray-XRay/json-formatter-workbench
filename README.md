# Code 格式化工作台

一个纯前端的多语言代码格式化工具，零依赖、零后端，打开即用。SQL 解析器 sql-formatter 15.9.0 已本地 vendor（`sql-formatter.min.js`），无需联网加载。

支持 **JSON、SQL、Python、Go、Java** 五种语言：工具栏选语言，或保持「自动检测」，粘贴代码后自动识别。

## 各语言功能

| 功能 | JSON | SQL | Python | Go | Java |
| --- | --- | --- | --- | --- | --- |
| 格式化 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 压缩（压成一行） | ✅ | ✅ | — | — | — |
| 验证 | ✅ 完整解析，报错带行列号 | ✅ 真实语法解析，报错带行列号 | 结构检查（括号、引号、缩进） | 结构检查（括号、引号配对） | 结构检查（括号、引号配对） |
| 树形视图 / JSONPath / 排序 / 转 YAML / 生成类型 / 对比 / 转义 / 修复 | ✅ | — | — | — | — |
| 复制结果（带颜色）/ 复制 Markdown 代码块 / 下载 | ✅ 带颜色 | ✅ 带颜色 | ✅ 纯文本 | ✅ 纯文本 | ✅ 纯文本 |

说明：

- **SQL 格式化**：sql-formatter 真解析（标准 SQL 方言），关键字大写，SELECT / FROM / WHERE / JOIN / GROUP BY 等子句分行，子查询按括号缩进；缩进跟随工具栏的缩进设置（2/4/Tab）。解析失败时（方言语法或语句有误）自动回退轻量版并在状态栏注明。
- **SQL 语法高亮**：输出区带颜色（关键字、字符串、数字、注释、函数名），跟随当前主题；复制结果、复制 Markdown 时 SQL 也带颜色（粘 Word/邮件保留主题色，Notion/Jira 按 SQL 自己上色）。
- **SQL 验证**：真实语法解析，报错带行列号（如 `第 1 行第 38 列附近，意外的 ;`）；但 sql-formatter 是格式化器不是严格校验器，`SELECT FROM WHERE` 这类语义错句它也会放过，只能拦住放错位置的 token（括号不配对、BETWEEN 缺值等）。
- **Python 整理**：去行尾空格、空行最多留 2 行、按 `:` 块结构重排缩进。缩进特别乱的代码按冒号结构理解，仍需人工检查。
- **Go / Java 格式化**：按大括号定缩进，分号换行，`if/for/while` 后留空格，`switch/case`、注解单独成行，保留原有空行。
- **压缩**：Python、Go、Java 不支持（换行有语法意义，或压行会改变语义），按钮会自动变灰。
- **验证（非 JSON、非 SQL）**：只做结构检查——括号、引号、注释是否配对，Python 外加缩进检查；不是完整语法校验，通过不代表编译一定能过。
- **自动检测**：按内容猜语言（`{`/`[` 开头且能解析就是 JSON；SELECT/WITH 开头是 SQL；`package`+`func` 是 Go；`public class`/`import java.` 是 Java；`def`/`import` 是 Python）。猜错时手动在工具栏选语言，选定后会记住，不再自动变。

## 通用功能

- **界面**：一行工具栏 +「更多工具」下拉菜单，JSONPath 栏按需展开，输入区自带示例/打开文件/粘贴/清空；左右栏可拖动调宽
- **树形视图**（仅 JSON）：可折叠的节点树，点击叶子值可复制；顶部搜索框按 key 或值过滤节点，Esc 或 × 清除恢复
- **修复 JSON**：自动修掉尾随逗号、单引号、未加引号的键、注释
- **JSONPath 查询**：支持 `$.a.b[0]`、`$..key`、`$.*`、`[*]`，点结果可复制
- **生成类型**：下拉选择 TypeScript / Go / Python，根据 JSON 推断类型定义，可复制或下载
- **转 YAML**：一键把 JSON 转成 YAML
- **JSON 对比**：粘贴第二份 JSON，逐行高亮新增 / 删除的差异
- **转义 / 去转义**：JSON 字符串与原文互转
- **分享链接**：把当前数据编进 URL，打开链接即是这份数据
- **历史记录**：最近 5 次输入，下拉可恢复；「更多工具」→ 历史旁边有「清空」按钮，一键删掉全部记录
- **多主题**：深色、浅色、复古、Oracle、Oracle 白、DataGrip、JetBrains 七种主题，右上角切换，自动记住
- **按键名排序**（仅 JSON）：递归排序所有对象键
- **粘贴后自动格式化**：可开关
- **文件支持**：打开 `.json` / `.sql` / `.py` / `.go` / `.java` / `.txt` 文件、拖放文件、下载结果
- **快捷键**：Ctrl+Enter 格式化，Ctrl+A 选中格式化结果，Ctrl+Alt+C 复制结果（带颜色，仅 JSON），Ctrl+Alt+M 复制为 Markdown 代码块，树形视图中 Ctrl+L 展开 / 再按一次折叠全部节点；Ctrl+Alt+S 或「更多工具」→「快捷键设置」可查看和修改全部快捷键，改完自动保存
- **复制 Markdown 代码块**：纯文本是 ```围栏（按当前语言标语言名），粘到 Notion / Jira 是代码块；JSON 还同时带一份带颜色的 HTML，粘到 Word / 邮件保留主题颜色
- **输入草稿自动保存**：输入框内容自动存到浏览器里，刷新或下次打开自动恢复；分享链接优先于草稿，点「清空」会把草稿一起清掉

## 本地运行

直接用浏览器打开 `index.html` 即可，或起一个静态服务器：

```bash
npx serve .
# 或
python3 -m http.server 8000
```

## 部署

纯静态站，可直接部署到 Vercel / GitHub Pages / 任意静态托管。
